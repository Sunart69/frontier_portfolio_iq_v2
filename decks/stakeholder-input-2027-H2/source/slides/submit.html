How to submit

Update your pre-filled template and return it; a check runs automatically

1

Get your template

Your GitHub issue links it: cycles/2027-H2/templates/, one file per owner, pre-filled with last cycle’s data

2

Update it

Keep sheet and column names; only your LOB’s rows; money in $K; months as numbers or names

3

Return it

Save as cycles/2027-H2/inputs/<input>__<LOB>.xlsx, e.g. budget__LOB-A.xlsx, by pull request or Upload files. No GitHub access? Email the portfolio lead.

4

Automatic check

Results post on your pull request within minutes; your issue closes when a valid file is merged

Each owner has a GitHub issue that links the template and states the due date. Return the file with the exact name shown; an automatic check validates it on the pull request and reports anything to fix. If you do not use GitHub, email the file to the portfolio lead, who adds it for you.
