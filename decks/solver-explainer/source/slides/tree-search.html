Step 4 · Pruned

Bound below the best plan: no plan beneath it is checked

Illustration of the method (branch-and-bound), not a log of the sample run. Pruning one branch discards every plan beneath it, which is how the solver proves a plan is within 1% of the best in under 5 seconds.

The solver never lists every plan. It builds a tree of yes-or-no choices. At each branch it computes a bound, the best value anything below could reach if limits were relaxed. If that bound cannot beat the best plan found so far, the whole branch is discarded without checking a single plan in it. Dashed boxes are pruned branches. The blue box is a complete plan that meets every rule.
